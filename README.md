## 🎯 Genel Bakış

Sosyal medyada artık sorun içerik bulmak değil, **doğru içeriği bulmak**.

**NOVASYON AI**, milyonlarca kullanıcısı olan **NSosyal** platformunu sıfırdan yeniden inşa etmek yerine; onun üzerine akıllı, görünmez ve güçlü bir yapay zekâ katmanı ekler. Keşfet, Trendler, Topluluklar ve Profil gibi kullanıcının zaten bildiği ekranlar aynı kalır — sadece çok daha akıllı hale gelir.

## 🖥️ Ekranlar

<br>

### 🧑‍💻 Kullanıcı Deneyimi

```
Keşfet  →  Kişiselleştirilmiş İçerikler  →  Etkileşim  →  Öneriler Güncellenir
```

| Ekran | Ne yapar |
|---|---|
| **Keşfet** | AI destekli öneri motoru, ilgi ve etkileşim sinyallerine göre içerik sıralar |
| **Trendler** | Sadece etkileşim sayısına değil; hıza, yayılıma ve ilgiye bakan ağırlıklı skorlama |
| **Topluluklar** | Kullanıcının ilgi alanına göre topluluk önerisi |
| **Ayarlar** | Her AI özelliği tek tek açılıp kapatılabilir |

<br>

### ✍️ İçerik Üreticisi Deneyimi

```
Paylaşım  →  AI İçerik Analizi  →  Skor & Duygu Analizi  →  Öneriler  →  Performans Paneli
```

| Ekran | Ne yapar |
|---|---|
| **Oluştur** | Başlık, etiket ve kategori önerileri sunan üretken AI desteği |
| **İçerik Analizi** | Duygu ve kalite skorunu sade, anlaşılır dille sunar |
| **İçerik Üreticisi Paneli** | Performans metriklerini yorumlayarak gösterir |

<br>

### 🏢 Marka Deneyimi

```
Arama  →  AI Değerlendirmesi  →  Uyum Skoru  →  Üretici Profili  →  Eşleştirme
```

| Ekran | Ne yapar |
|---|---|
| **Eşleştirme** | Yüzdelik uyum skoruna göre hızlı, veri temelli üretici seçimi |
| **Uyum Detayı** | Skorun hangi kriterlerden oluştuğunu şeffaf biçimde gösterir |

## ⚙️ Teknoloji

<br>

<div align="center">

| Katman | Teknoloji |
|---|---|
| **Arayüz (Prototip)** | HTML · CSS · JavaScript |
| **Mobil Hedef** | Flutter · Dart |
| **Doğal Dil İşleme** | Transformer tabanlı Türkçe modeller (BERTurk) |
| **Duygu Analizi Verisi** | BounTi · TREMO |
| **Öneri Sistemi** | Hibrit — içerik tabanlı + işbirlikçi filtreleme |
| **Eşleştirme Algoritması** | Embedding tabanlı benzerlik (cosine similarity) |
| **Versiyon Kontrolü** | Git & GitHub |

</div>

<br>

**Mimari felsefe:** Arayüz ve AI modelleri birbirinden bağımsız servisler olarak tasarlanır. Bir modeli güncellemek, uygulamanın tamamını yeniden derlemeyi gerektirmez.
